# Лабораторна робота №1: Класи та об'єкти в C#

## Опис проекту
Цей проект є консольним додатком на C#, розробленим в рамках лабораторної роботи з Об'єктно-орієнтованого програмування. Додаток керує колекцією об'єктів відеоігор (`VideoGames`) і дозволяє виконувати базові операції (CRUD), а також взаємодіяти з поведінкою об'єктів.

## Функціонал
* **Додавання гри:** Введення параметрів (назва, жанр, рейтинг, рік, ціна) з повною валідацією.
* **Перегляд таблиці:** Виведення збережених ігор у відформатованому вигляді.
* **Пошук:** Знаходження ігор за жанром або роком випуску.
* **Поведінка:** Симуляція запуску та виходу з гри, що впливає на лічильник гравців онлайн. Оновлення рейтингу гри.
* **Видалення:** Видалення ігор за індексом у таблиці або масове видалення за певним жанром.

## Структура класів
* `Program` - містить точку входу `Main` та логіку консольного меню.
* `VideoGames` - містить поля сутності, конструктор та методи для зміни лічильника гравців.
* `GameGgenre` - enum для фіксованого вибору жанрів.

## Як запустити
1. Склонуйте репозиторій.
2. Відкрийте рішення (Solution) у Visual Studio.
3. Натисніть `F5` або кнопку `Start` для компіляції та запуску програми.
